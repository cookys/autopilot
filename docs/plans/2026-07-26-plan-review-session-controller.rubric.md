# Frozen review rubric — Durable Heterogeneous Plan-Review Session Controller

Only the following criteria may admit a blocking plan finding.

- R1: Repo + ticket + frozen rubric is durable identity and cannot be reset by runner/process/session changes.
- R2: Transport attempts are distinct from semantic generations and bounded to two per seat/generation.
- R3: A frozen exact-tuple manifest supports 1–4 seats; panel width is one generation.
- R4: Substitution is manifest-declared, readiness/family checked, recorded, and does not create a ticket.
- R5: Findings have stable fingerprints, provenance, dedupe, rubric mapping, and depth-0 disposition.
- R6: Only accepted frozen-rubric blockers authorize generation 2; all other useful findings become backlog candidates.
- R7: Generation 2 is terminal and generation 3 is mechanically impossible for the same ticket.
- R8: Artifacts distinguish transport status, semantic verdict, attempt, generation, and terminal state.
- R9: Legacy chair/deep callers remain compatible.
- R10: Plan includes executable red cases for retries, drift, duplicate findings, supplements, and cap evasion.
- R11: PRS consumes the shared mechanical runner envelope and alone validates purpose-bound
  plan-review semantics; transport truth is not duplicated and raw artifacts cannot cross
  controller authority.

Next-slice readiness means no implementer must invent manifest, retry, adjudication, aggregation, or
terminal semantics.
