# knowledge-routing-config — autopilot's own

autopilot is the exception the shipped default deliberately does not encode: it is a plugin whose
repo contains the skills themselves, so a rule that binds *other skills* has a real home here in a
reference directory. Every consuming project's default is `CLAUDE.md`, which is the right answer
where there are no shipped skills to bind.

Contract and role meanings: [`../project-config-template/knowledge-routing-config.md`](../project-config-template/knowledge-routing-config.md).
