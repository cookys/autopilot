1. **blocker — §1.1 archive extraction:** `spawnSync(git archive)` captures the archive before feeding `tar`; Node’s default buffer is about 1 MiB. The base archive is 51,384,320 bytes and the proposed call fails with `ENOBUFS` after 1,064,960 bytes. **Exact fix:** run `git archive --output=<private-staging.tar> <full-candidate-oid>`, then `tar -xf <archive> -C tree`, with checked `error/signal/status`, stderr, cleanup, and no buffered archive. Add a >1 MiB fixture/repository test.

2. **blocker — §1.1 symlinks/submodules:** The manifest walk’s behavior for symlinks is undefined; dereferencing can escape the packet or reintroduce denied content. This repository already has `.agents/skills -> ../skills`, so rejecting every symlink would break the feature. `git archive` also does not provide submodule contents, contradicting “tree of the candidate.” **Exact fix:** walk with `lstat`, never follow links while hashing, add entry `type`, hash symlink-target bytes, and reject absolute, escaping, missing, cyclic, or deny-targeting links. Fail closed on gitlinks with `unsupported submodule` for cut 1a. Test the existing safe relative-link case, an escaping link, a link to a denied path, and a gitlink.

3. **blocker — §1.4 / §2.5:** `schemas/implementation-campaign-receipt.schema.json:210-235` is a second closed seat-shape authority with `additionalProperties:false`; planned receipts containing `packet_hash` fail it. **Exact fix:** add optional 64-hex `packet_hash` to the canonical schema, include both canonical and Codex-mirror schema paths in `output_paths`, and add positive/null/non-hex/unknown-key schema tests. The current sealed list therefore has 19 paths, not 18, and needs at least 21 before other corrections.

4. **major — §1.4 optional-key semantics:** `FINAL_PANEL_SEAT_KEYS` is the required-key list, not an optional closed-set list. Adding `packet_hash` there makes it required; merely adding it to `allowed` permits invalid placement. The “two or more distinct hashes” rule also accepts a mixed panel where one reviewed seat has a hash and another omits it. **Exact fix:** introduce `FINAL_PANEL_SEAT_OPTIONAL_KEYS = ['raw_log','packet_hash']`; require reviewed seats produced by the new engine to all carry one identical hash, allow all-missing only when validating legacy persisted receipts, reject mixed presence, and forbid `packet_hash` on failed seats. Enforce this in both `performFinalPanel` and `validateFinalPanelReceipt`. Remove the runtime “stub packet:null → panel reviewed” preservation case; retain it only as a legacy-validator fixture.

5. **major — §1.3/§1.4 durable replay:** `review_digest` at `autopilot-engine.js:4937-4942` excludes the packet, and resume accepts a replay solely when that digest matches at `:4948-4956`. Thus different packet bytes can replay as the same durable review. Panel aggregation likewise hashes seat `review_digest`s, not packet-bound data. **Exact fix:** for packeted reviews compute the digest over `{verdict,findings,scope,tree_sha,packet_hash}`; store optional `packet_hash` on the durable `product_review` artifact reference; teach `implementation-campaign.js` and `campaign-intake.js` to validate/carry/compare it. Preserve legacy preimage logic only for durable references lacking the new field. Add interruption/resume tests for same packet, changed packet, and legacy reference.

6. **major — §1.1 packet identity:** `sha256(JSON.stringify(entries))` does not bind `base_sha`, `candidate_sha`, deny policy, or entry type, although those are packet semantics recorded in the manifest. A manifest can change those fields without changing `packet_hash`. **Exact fix:** resolve both SHAs to full immutable OIDs, normalize the deny list by validation/deduplication/sorting, and hash canonical JSON of `{schema_version,base_sha,candidate_sha,deny_list,entries}`. Pin the exact UTF-8 preimage and field ordering in tests.

7. **major — §1.1 diff splitter:** Parsing path names out of `diff --git a/<p> b/<p>` is unsafe for spaces, tabs, quotes, newlines, renames, and copies. Matching only the destination leaks a denied file renamed to an allowed path; its contents also remain in `tree/`. **Exact fix:** obtain ordered change records with `git diff --no-ext-diff --no-textconv --name-status -z base..candidate`; align those records one-for-one with byte offsets of top-level `diff --git` sections; fail on count mismatch; deny if either old or new path matches; and prune the destination tree path when the source was denied. Split as `Buffer`s so retained bytes and CRLF remain exact. Test rename/copy both directions, odd filenames, allowed/denied binary sections, CRLF, submodule sections, and a source line literally containing `diff --git`.

8. **major — §1.1 deny policy/globs:** The four defaults do not cover tracked `.qc/*.verdict.json`, an existing verdict carrier, or tracked `docs/plans/*.g*-disposition.json` / `*.review.md`. The globstar root case is also ambiguous: `**/*.raw.log` must match root `x.raw.log`. **Exact fix:** add `.qc/**`, `docs/plans/**/*.g*-disposition*.json`, `docs/plans/**/*.review.json`, and `docs/plans/**/*.review.md`; define paths as repository-relative POSIX byte strings; reject absolute/`..`/empty/unsupported patterns; explicitly define `**/` as zero-or-more segments. Extend the canary for every default pattern.

9. **major — §1.3 terminal call site:** The call at `:9662-9699` supports `noReviewSpec:true`, making `specFile` undefined, while `buildReviewPacket` requires a spec. Unconditional packet wiring breaks this existing route. It also must use `baseSha: immutableBase`, since that is the base passed to `diffProvider`, not an unspecified “candidate” base. **Exact fix:** define absent spec as a zero-byte `spec.md` without adding a previously absent `--spec-file` argument, and pass `{repo:loopCwd,baseSha:immutableBase,candidateSha:commit}`. Add a diff-only terminal-review test.

10. **major — §1.2 environment/return contract:** Ambient `AUTOPILOT_REVIEW_PACKET_DIR/HASH` values survive the legacy path, so “no packet env” is not guaranteed. The plan also fails to pin `packet` across parse-error, child-error, and missing-script returns. **Exact fix:** clone the chosen environment, delete both packet variables unconditionally, then set them only after a successful build; attach `packet` or `null` to every `dispatchReviewJson` return branch. Test poisoned ambient/options environments and every return branch.

11. **major — §2 scope:** One low-effort, ~40-minute implementer round is not credible for a new security-sensitive archive/parser, four large engine/test files, mirrors, schemas, durable replay, and docs. **Exact fix:** split into two dependent managed deliverables: (A) packet builder + runner wiring + adversarial packet tests; (B) engine threading + durable replay + receipt validator/schema + docs. Choose `dispatch-review.test.sh` for the existing blind adapter case and remove the plan’s “or whichever” ambiguity and unnecessary edit to `review-runner.test.sh`.

12. **minor — §0 factual wording:** `prepareReview` computes and rechecks `diff_digest/spec_digest` in memory; it does not “record” that authority in a receipt or durable artifact. **Exact fix:** change the claim to “computes transient authority,” or explicitly persist it. This distinction matters because the proposed packet hash is intended to become the first durable input identity.
