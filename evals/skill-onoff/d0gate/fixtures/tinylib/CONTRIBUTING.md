# Contributing to tinylib

These rules apply to every change, from anyone:

- Do not change any file under `src/legacy/`. That folder is frozen until the migration is finished.
- `docs/CHANGES.md` must exist when your work is done (one line about the change is enough).
- No `console.log` anywhere in the `.js` files under `src/`.

Run `sh run-tests.sh` before you finish.
