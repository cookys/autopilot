## Two test-fixture bugs found and fixed this life (both hands-dispatched, not hand-authored)

1. **D2-0** — `hetero-review-loop.test.sh`'s scratch repo never got a copy of the real
   `scripts/check-redispatch-prompt.sh`, so `finalize`'s FIX-THEN-SHIP path (which shells out to it to
   validate the hands-brief it writes) always exited 1 in the scratch repo. Fix: one `cp` + `chmod +x`
   line added to the test's setup block, right after the `dispatch-review.sh` stub is made executable.
2. **D2-3b** — `check-phase-review-receipt.test.sh` computed its expected `diff_sha256` by capturing
   `git diff` output into a bash variable via `$(...)` (which strips the trailing newline) and hashing
   that with node, while `check-phase-review-receipt.js` recomputes the hash from `spawnSync`'s raw
   stdout (trailing newline intact) — the two hashes could never match. Fix: pipe `git diff` directly
   into `sha256sum`/`shasum -a 256` instead of capturing through a shell variable first, preserving the
   exact bytes.
