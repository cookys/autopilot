4. **Rehearse the deploy and recovery on a production-sized copy.** Run the exact upgrade against roughly two million rows and test a fresh install through the normal bootstrap path. Measure the backfill and column drop separately, including lock duration, temporary disk and journal or WAL growth, and total downtime. Verify that the backfill preserves existing names and that the new application reads, writes, and renders labels correctly. Test restoring a pre-deploy backup and starting the old release. Start the new release and verify the final schema, unchanged user count, expected labels, and successful writes before reopening traffic.
