# Frozen Rubric — Dispatch Worktree Lifecycle Budget

- R1: The plan accurately identifies the current control surfaces and the concrete gap that allowed one logical project to accumulate retained worktrees and process branches.
- R2: The plan defines a race-safe per-root worktree occupancy cap enforced before creation without deleting live, dirty, unsupported, malformed, legacy, or foreign-owned state.
- R3: The plan defines safe immediate and finish-time worktree reclamation with exact identity, liveness, cleanliness, revalidation, and branch-tip preservation.
- R4: The plan prevents review-generation budget reset across new processes, sessions, providers, and branch names by using canonical repository identity plus stable root and loop identity.
- R5: The plan makes zero owned worktrees and exact preserve-first branch disposition mandatory before finish-flow clears orchestration state.
- R6: The test strategy includes executable positive oracles and negative controls for concurrency, retries, liveness, dirty state, malformed/legacy markers, exact branch containment, races, and finish ordering.
- R7: The plan is implementable in bounded phases, preserves direct-dispatch backward compatibility, and excludes unrelated worktrees, dirty auto-deletion, and uncontained branch deletion.
- R8: The file map and documentation work cover the canonical scripts, engine CLI, ledger/config surfaces, L5/L6/finish-flow skills, references, and validation commands.
