## 1. 四層資訊架構（L0–L3）與版面規則

核心鐵律：**單一事實只出現於唯一位置（One Fact in One Place）**，將 `FACT_OWNER`（`mods/live/ui.ts:385-400`）由跨分頁延伸至同畫面跨層，嚴格分離「狀態摘要、清單導覽、單卡內文、底部控制」。

### 熱區（Hot zone）原則

依 PM 裁示 `01M773F3`（2026-11-12），版面配置以**熱區（Hot zone）**為最高指導原則：
- **規則定義**：
  1. **操作本體貼底（Act-on at bottom）**：操作者當下必須動手的項目——正在決定的卡片本體、其選項按鈕、以及送出／撤回控制列——一律置於窗格最底部，緊鄰宿主輸入框（input box）。
  2. **決策依據同行並排（Deciding context beside, in the same rows）**：做出該決定所需的資訊——背景（`background`）、建議與推薦理由（`recommendation`／`why`）、以及相關的最近提問與回覆（「我問的問題」）——必須置於當前卡片**旁邊（同一批水平列內左右並排）**，嚴禁拆到上方獨立區塊迫使視線上下跳躍。
  3. **其餘資訊置頂且可收合（Cold zone above & collapsible）**：所有非當下動手的總覽資訊——全局摘要列（summary lines）、待決佇列總覽（queue overview）、資料年齡（data-age）與異常清單——一律置於熱區上方，且支援收合（collapse）。
- **設計理由（Why）**：操作者以底部的宿主輸入框為作業原點（打字向 PM 提問、按 `f` 填入 `[待決回覆]` 模板、切換焦點選答皆從輸入框出發）。若將待決卡推離底部，或把背景、建議與最近問答放在上方獨立區塊，眼球就必須在底部輸入框與中上段視窗間反覆大幅垂直往返（vertical eye travel）；把操作本體貼底、決策依據同行並排，視線只需在底部幾列內水平掃視即可完成判斷與送出。
- **對 L0–L3 的由上而下排序約束（v1 → v1.1 修正）**：
  - **上方冷區（Cold Zone，可收合）**：**L0**（頂部單行狀態帶；指揮台之 `summaryRow`、`ageRow` 資料年齡與可收合 `exceptions` 皆置於此，修正 `band.tsx:265` 選單夾底與 `commandtab.ts:139` `ageRow` 壓底）→ **L1**（全寬單行待決佇列總覽，可按 `q` 收合為 1 列標頭；修正 v1 將「我問的問題」混入 L1 上方區塊之設計）。
  - **底部熱區（Hot Zone，緊貼輸入框）**：**L2**（直接位於 L3 正上方；`>= 120` 欄採左右雙欄並排且雙欄皆**貼底對齊 `justifyContent="flex-end"`**：**L2 左欄**放當前選中卡題目、選項與不授權，**L2 右欄**於同一批列放「我問的問題」、背景與建議理由）→ **L3**（最後渲染列群，緊貼輸入框，放選項／送出／撤回等有效按鍵）。

### 展開高度、色彩語意與窄寬度（80–119 欄）熱區退讓順序

- **內容驅動高度（上限 60%、零空白填充列）**：展開區總高度 = `冷區列數 + 熱區 max(L2 左欄, L2 右欄) + L3 列數 + 外框`，隨內容伸縮，上限為終端機總列數 **60%**（`Math.floor(rows * 0.6)`）。超出 60% 時於 L2 右欄依據或超長卡啟用捲動視窗與 1-cell 捲軸（`cardSplit`、`fixedWindow`/`thumbOf`，`mods/live/band.tsx:365-383`、`mods/live/scrollmath.ts`），左欄選項與 L3 釘死底部不捲動。廢除 `BODY_ROWS = 8` 保底（`shell.ts:20`、`register.ts:1370`）與 `while (rows.length < winRows)` 補空行（`band.tsx:378`、`shell.ts:270`）。
- **色彩與強調（遵循 `mods/CLAUDE.md:7`、`mods/live/design.md`、`mods/live/ui.ts:79-99`）**：僅透過 `PALETTE`（`ui.ts:87`）使用 8 個語意文字色（`attention`/`here`/`broken`/`done`/`running`/`idle`/`structure`/`action`），嚴禁 `backgroundColor` 與 `inverse`（`ui-lint.test.js:133, 241`）；粗體僅限 `BOLD_USES` 7 處（`ui.ts:89-99`）；符號取自 `GLYPHS`（`ui.ts:65-75`）並經 `mods/live/glyph-check.js:7-15` 單格驗證。
- **80–119 欄熱區存活與移出優先序（Hot-Zone Fallback Priority）**：
  1. **最優先存活於熱區底部（Survives first）**：**動手控制項（Act-on controls）**——L3 送出／撤回與有效熱鍵列，以及 L2 左欄當前卡片的**選項按鈕與問題本文**——永遠留在窗格最底部緊貼輸入框，絕不因窄寬度被擠走或收合。

## 2. 決策依據右欄與「我問的問題」規範（Hot-Zone Context Column in L2）

現行 `recentLines`（`mods/live/tabs.ts:459-483`）與 `groupRecent`（`mods/live/model.ts:1820-1885`，`RECENT_MAX = 3`、`RECENT_COLLAPSED_CHARS = 60`）將最近對話孤立在 `Now` 分頁最底部預設折疊區（`SECTION_ORDER.now` 末項，`ui.ts:405, 415`）；而本準則 v1 初稿曾將「我問的問題」放在 **L1 右區（位於 L2 卡片上方）**，仍違反熱區原則，迫使操作者視線從底部輸入框與選項向上跨越外框才能對照問答。

## 5. 宿主限制（Host Constraints）

設計與實作須在 Claude Code 終端機宿主（Host TUI）對 `AbovePrompt` 與 `Pane` 之硬性邊界內運作：

1. **L3 快速列與宿主輸入框之間的 1 列空白**：`mods/live/band.tsx:35-38` `stackRows` 未加備用列（no spare row）；`mods/live/band.tsx:265-267` `Shell` 將 `key="quick"` 作為最後一個 `Box`（由 `mods/live/register.ts:1408` 交給 `stackRows`）；`mods/live/live.test.ts:7122-7130` 與 `mods/live/live.test.ts:7398-7399` 亦驗證樹末列即為 `quick`。故該空白係由宿主外框自行繪製而非 `mods/live` 所生（*註：目前由原始碼與單元測試推導，尚未拍攝實機截圖〔real-terminal screenshot not yet taken〕，後續須補拍確認*）。
2. **超出 `maxRows` 時宿主強制開窗並以 `"n more"` 遮蔽底部熱區 L3（`mods/live/band.tsx:33-34`、`mods/live/register.ts:1362-1365`、`mods/live/design.md:28`）**：回傳樹總列數超過 `e.props.maxRows` 時，宿主會把最後一列（L3 操作列）藏在 `"n more"` 後面，直接破壞熱區貼底，故總高須嚴格 `<= maxRows`（`avail = rows - 6`）。
3. **視窗外（Off-tree）`Button` 的數字熱鍵 `hotkey` 自動失效（`mods/live/register.ts:1375-1379`）**：宿主僅對掛載於渲染樹中的 `Button` 攔截 `hotkey`；超高卡進入 `cardSplit`（`mods/live/band.tsx:362-383`）時須將選項按鈕抽離至底部固定 `strip`。
4. **宿主打字框僅支援填充（`$.prompt.fill`）不支援代客送出（`mods/live/register.ts:1341-1347`、`mods/live/live.test.ts:7344-7356`）**：按 `f` 僅能填入 `[待決回覆]` 模板，須由操作者在下方輸入框親自按 `Enter` 送出（此即操作者以輸入框為作業原點之宿主根源）。
5. **`Pane` 跨分頁共用單一宿主捲動偏移（`mods/live/register.ts:1508-1512`）**：切回自繪捲動視窗的「待決」分頁時，須由 `hostScrollHome` 呼叫 `$.ui.scroll({ in: PANE_ID, to: 'start' })` 歸零，否則非零偏移會把底部熱區擠出畫面。
6. **宿主無讀取當前焦點 API（`mods/live/register.ts:1473, 1483-1489`）**：批次答卡灰化後須由插件自存 `decideFocus` 並呼叫 `$.ui.focus` 主動修復焦點。
7. **未掛載 `Raster` 拒絕 `$.ui.blit`（`mods/live/register.ts:1414-1415`）與 `$.env.get` 字面量限制（`mods/CLAUDE.md:9-11`）**：未掛載下層 `Raster` 時宿主以 `{ deny }` 拒絕繪圖；`$.env.get` 首參數須為字串字面量（`ui-lint.test.js` L11 檢查）。
