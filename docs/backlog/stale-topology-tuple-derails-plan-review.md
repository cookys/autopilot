# A stale topology tuple derails a plan-review loop, and the failure is unreadable

Section copied from the shared sidecar `docs/backlog/live-state-dir-context-budget-test-strength-two-surviving-mutants-one-vacuous-of.md` (other sections omitted). Original size label: M.

- **Context**: `~/.autopilot/topology.json` recorded the reviewer seat `qwen3.8-max-preview@qoderclicn`. The installed build offers `Qwen3.8-Max`; the invalid name makes the CLI print an error and the wrapper exit 3 with empty stdout and empty stderr, so the seat looks like a dead runner rather than a bad tuple. With that seat required, generation 1 ends terminal with `policy_reason: required_seat_transport_exhausted`, and the completed seat's real findings land in `unratified_observations` where the receipt checker cannot see them. The escape — correcting the model name — is itself refused because durable identity or the frozen rubric drifted. The plan-review header documents clearing the logical plan's sealed state. The real cost is that nothing in the failure path points at it, and the diagnosis starts from an exit 3 with no output. Observed 2026-09-08 on `fleet-comms-2026-09-08`.
- **Trigger**: the next plan-review loop that ends `required_seat_transport_exhausted`, or the next topology regeneration.
- **Guardrails**: Do not relax the seal for semantic drift. A seat that never produced a parseable reviewer artifact has no verdict to dodge, so replacing only its tuple is not evasion. A seat that reviewed and dissented must stay frozen. The successor artifact must record the predecessor's id and the reason. Two cheaper mitigations that need no seal change: `resolve-dispatch-topology.js` should validate a recorded model against the runner's own list (`--list-models`) instead of trusting a baseline event, and the wrapper should surface the runner's stderr rather than discarding it.
- **Related**: `scripts/resolve-review-loop.sh` also resolved `plan_review_resolved_from: native-fallback` on a host with three qualified seats, purely because `~/.autopilot/topology.json` did not exist yet.
