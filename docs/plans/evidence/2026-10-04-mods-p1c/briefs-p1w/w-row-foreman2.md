## Commit 2 — `fix(hooks): attention keeps one entry per pending dialog; a subagent's dialog survives the main thread's Stop (mods P1W W4 gate)`
Evidence `gate/runs/l4f-done-b2/20261005T112728Z`: a reviewer subagent's Bash dialog ("1 of 2") was on screen with no attention file. Two wipe paths in `hooks/awaiting-owner.js`: the main thread's Stop removes everything, and a PostToolUse of ANY agent with the same tool_name removes the file.
Fix (additive to `autopilot.attention/1`; top-level fields keep their meaning so `mods/live/model.ts` and `gate/check.js` stay compatible):
- New field `pending: [{ agent_id|null, tool_name, input_digest, kind, summary, since }]`. Top-level `kind/tool_name/summary/since` = the OLDEST permission/question entry; `idle` only when no permission/question entry exists. File removed when nothing is pending.
- PermissionRequest appends (or refreshes `updated_at` of) the entry keyed (agent_id, tool_name, input_digest) — digest = sha256 of the canonical JSON of tool_input, truncated.
- PostToolUse removes the exact (agent_id, tool_name, digest) entry; if none matches, the OLDEST entry with the same (agent_id, tool_name) (Tab-to-amend changes the input). Never an entry of another agent.
- Stop / UserPromptSubmit remove only main-thread entries (`agent_id: null`) and idle. SubagentStop(agent_id) removes that agent's entries (the only end for a human-denied subagent dialog). SessionEnd removes all. Notification permission_prompt heartbeats; idle_prompt still yields to any permission/question entry.
- If PermissionRequest inside a subagent does NOT carry agent_id (verify-first): fallback — a PermissionRequest arriving while `<live>/turn/<sid>.json` is `ended` is not the main thread's; tag it `agent_id: "unknown-subagent"` and let only SubagentStop (any agent) or SessionEnd/UserPromptSubmit end it. Document whichever applies in the file header.
- Old-shape files (no `pending`) are read as one main-thread entry (upgrade in place mid-session).
- Update any attention schema under `platforms/codex/plugin/schemas/` and `hooks/README.md` wording; run the codex sync.
Tests RED-first + mutations: two agents same tool_name — one's PostToolUse leaves the other's entry; main Stop leaves a subagent entry; SubagentStop clears only its agent; amended input falls back to oldest same-(agent, tool); top-level = oldest; idle never overrides; old-shape upgrade; knob off.
