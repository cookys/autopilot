# A campaign that passed through BOUNDARY_REJECTED can never reach terminal success: the controller transcript audit blocks it

Source: found 2026-10-03 during the v2.36.111 landing (unit A-r2 hand observed it in a fixture; confirmed as a product defect by a read-only debugger run against f197fc09 with a control). Full report: `docs/plans/evidence/2026-10-03-v111-resume-and-review-budget/DEBUG-boundary-terminal-audit.md`.

- **Trigger**: FIRED — any managed campaign whose implementer returns `boundary_rejected`, is resumed with a git-bound candidate, and reaches composition `ready` is blocked at `controller_work_order_terminalize` (`transcript_incomplete`). Next wave.
- **Context**: two halves, both written at boundary time into immutable, digest-bound rows. (1) The dispatch record's `result_receipt_digest` comes from `mutation.writer_fence.receipt_digest` (`src/engine/campaign-composition.js` ~1640-1670); a boundary_rejected mutation (`src/engine/autopilot-engine.js` ~7846-7870) carries no `writer_fence`, so it is null and `rebuildTranscriptAudit` (`src/engine/controller-execution.js` ~3926-3932) rejects it. (2) The `campaign_boundary_receipt` pushed into `controller.audit_events` (`campaign-composition.js` ~1773-1820) has no `root_run_id`/`work_order_id`, so the tuple check (`controller-execution.js` ~3525-3530) reports `undefined/undefined`. Repro: xproc-driver shape with run1 parking in boundary_rejected → run2 `--resume` ends `blocked`; the same driver without the boundary ends `converged`. Fix shape: stamp the controller tuple at the producer (outside the receipt digest body) and give the boundary dispatch a real receipt digest (e.g. the boundary receipt's `dispatch_result_digest`) at write time — never null, never fabricated; the audit's requirements stay unchanged (mechanism change). Also fix `hooks/tests/autopilot-engine-boundary-resume.test.sh`: its green stage prints `green_reason=git worktree command exited with status 1` and never asserts the final status (fixture `worktree_instance_id` is `sha256(path)`, not the filesystem-instance id `repair-lineage-cleanup.js` expects; no `.autopilot-worktree` marker; stub appender skips the terminalize). Regression: converged after a boundary, audit rows all carry the tuple, a tampered tuple/digest still blocks.
- **Effort**: M
