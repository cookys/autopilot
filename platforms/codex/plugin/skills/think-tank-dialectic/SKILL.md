# Think Tank Dialectic — Hegelian Deliberation

## Dispatch Chains (auto-injected)
!`cat .claude/dispatch-config.md 2>/dev/null || true`

A DIFFERENT tool than `think-tank`, not an upgrade: resolves genuine stalemates
via Thesis → Antithesis → Synthesis. Cost is high; use is rare by design.

Hard rules (the non-negotiables):
- **Never first-resort**: reach for `autopilot:think-tank` first; escalate ONLY when
  its Decision Brief shows LOW consensus AND the decision is costly to reverse. Do
  not skip think-tank for a fresh question.
- **Max 2 rounds** (there is no R3); session re-entry ladder (2nd invocation on the
  same confirmed problem = Quick Synthesis, 3rd = refuse with the four-option exit).
- **HIGH R1 consensus (≥5/6) auto-downgrades** — no forced dialectic on an aligned panel.
- **Synthesis is NOT a compromise**; if no honest higher-order integration exists,
  the brief says so instead of faking one.
