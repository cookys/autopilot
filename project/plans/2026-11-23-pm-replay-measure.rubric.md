# Rubric（凍結，PM 省額度 replay 量測計畫 G1）
每項逐一判定：滿足／不滿足／證據不足，附計畫行號。阻擋性發現必須有可到達的情境（輸入或狀態 → 錯誤結果），否則只算備註。

- R1: [比得公平] 固定輸入只改一個開關，差確實只來自該開關；stub 查表未命中、分歧事件、預填 context 的暖快取不會讓兩臂不對等。
- R2: [不送真訊息] 重放全程不碰真 fleet、真 repo、真設定目錄；負控制足以證明 stub 層攔得住。
- R3: [決策一致率] 一致率定義可計算、門檻（低於基準臂 5 個百分點不得上線）能防止為省而亂裁，且不會因 stub 分歧而偽高或偽低。
- R4: [模擬與實測分開] S4、S5a、autocompact 等無法真重放的開關，被明確標為模擬，不被當成實測成本。
- R5: [成本可控] 預估、硬停損、池的選擇可行，量測本身不吃掉被省的 PM 額度。
- R6: [資料界線與步驟] 切片由 PM 帳號跑、本席不讀原始 transcript；fixture 祕密掃描與凍結成立；步驟和日期可行。
